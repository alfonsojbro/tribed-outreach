Before paid profile/post research for any Tribed outreach prospect, demo, /launch preview or revision, read the current `outputs/outreach-apify-policy.md` on `alfonsojbro/second-brain` main (use its current checkout or authenticated GitHub read) and discover Tribed's `get_apify_budget_status`, `run_budgeted_apify_actor`, and `collect_budgeted_apify_run`. The Apify connector's `call-actor`, direct HTTP/Bash launches and tasks are not alternatives. Collect existing requestKeys; preserve retry/unknown-start reservations and all sending/ownership/qualification holds. Do not raise account limits or buy credits. If policy, usage or guard tools cannot be read, stop paid research and continue sufficient free/cached material, or report the missing evidence for a deferred build.

Reuse existing qualified material, public websites and transcripts first. A genuine demo yes does not create a new paid-research allowance. Every handoff to a demo skill, linked session or subagent must carry this paragraph, the policy location, current budget reading, existing requestKeys/unknowns, available cached sources and the missing evidence; the parent owns paid actor calls unless an explicitly designated builder uses the same shared guarded path. Never give each builder a spend allowance. A successful external scrape is not a budgeted run or a delivered message. Keep actual cost, maximum commitments, qualified usable leads, stages and deliveries separate. This instruction does not grant permission to send messages or weaken the existing send gate.
