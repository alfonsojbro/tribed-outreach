# Alfonso's voice — the live fingerprint

Read this before writing or editing ANY message copy, in every mode. This file outranks generic craft instinct: when a sentence you wrote sounds better than something Alfonso would type on his phone, plainer it down to match this file.

This file is ALIVE. It grows from two sources: the voice interview (sections 1-2) and the self-upgrade loop (section 3). It is never finished.

## How the self-upgrade loop works (every session, every mode)

Every time Alfonso edits a draft you wrote, rewrites your suggestion, or says a line "doesn't sound like me", the difference IS voice data. Do this on the spot:

1. Diff his version against yours. Name the lesson in one line: what he removed, what he replaced it with, and the general rule if one is visible ("cut the second clause of the CTA", "he says X, never Y").
2. Append it, dated, to section 3 below, in the skill SOURCE repo: `~/Documents/Projects/tribed-outreach/skills/tribed-outreach/references/voice.md`. That path is the only copy that ships; editing any other checkout is a no-op.
3. If the session cannot write there (hosted, no repo access), print the dated lesson line and tell Alfonso to drop it into section 3.
4. When the same correction shows up twice in section 3, promote it into section 1 as a rule and leave the log entries in place.

Never log a content correction (wrong fact, wrong price, wrong anchor) here — only voice: word choice, rhythm, punctuation, register.
